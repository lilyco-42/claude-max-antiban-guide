## 一、Claude 封号底层逻辑

平台判断封号的核心只有一条：**你像不像来自它不支持地区的人**。条款里的另两条红线（蒸馏/高并发/接第三方工具、发违规内容）只要不主动作死就不会触发。

**注册是最关键的一步**：注册后头几天平台会评估环境风险，主要看浏览器是否暴露真实位置/IP、注册 IP 是否在海外且未被滥用。环境干净、行为正常、邮箱正经，号一开始就是干净的。

---

## 二、提高注册时账号权重

注册用单独购买的**美国静态住宅 IP**（几十元/月即可，不必追高价"纯净独享"）：

- 地区选美国，时区/语言与 IP 城市对齐（加州 → Los_Angeles，纽约 → New_York）；
- 选**静态**不选动态，注册过程出口始终同一地址；
- 商家返回的 **IP、端口、账号、密码** 四样存好，后续填指纹浏览器 + 手机小火箭各用一次。

---

## 三、用指纹浏览器装成美国用户

用比特浏览器类指纹浏览器，一个窗口强制走代理：

- 代理类型 **Socks5**，填入上面四样；WebRTC / 地理位置选**禁止**，语言全英文，时区随 IP；
- 指纹参数一键随机生成；
- 配好打开 `ipinfo.io` 验证出口 IP 在美国、城市与时区一致；
- 邮箱推荐 **Proton**（会拦截 Anthropic 邮件里的跟踪器，避免打开邮件泄露真实 IP）；验证链接一律在指纹浏览器窗口内打开；
- 注册 Claude 用邮箱登录，套餐先选 **Use Claude for free**，像普通新用户一样用几天；
- **最容易翻车**：在日常浏览器里点开 Claude 邮件链接 → 真实 IP 泄露。
- 付款时若弹 **KYC**，别硬过，直接重新注册新号。

## 四、清除设备指纹

订阅和接 Claude Code 都在自己电脑上完成，先把电脑收拾干净：

1. **系统时区改台北/新加坡**（UTC+8，显示时间不变，但系统时区不再是"中国"）；
2. **清本机残留记录**：完整备份 `~/.claude`，清缓存日志；删除内容进带时间戳的废纸篓，不永久删除；改动大的项由自己选择；输入一次 CONFIRM 才执行。macOS 支持，Windows 未测试。

---

## 五、不暴露自己的 IP

- **反向分流**：国内域名/IP 白名单走直连，其余全部走海外出口（别只给 claude.ai 配代理，它可能调用第三方服务）；
- 开 **TUN 模式**，让终端里的 Claude Code 也走代理（Clash 默认"系统代理"不覆盖命令行）；
- **兜底不直连**：梯子断了宁可断网，也不让流量回落直连；
- 验证：断掉海外节点后 claude.ai 打不开、国内网站照常，即正确。配置可直接让 Agent 按文中 Prompt 代改。

## 六、订阅 Claude 账号

两条路线二选一：

| 路线 | 需要 | Max 20x 价格 | 被封 | 麻烦程度 |
| --- | --- | --- | --- | --- |
| 网页订阅 + 海外卡 | 能海外付款的卡（部分开卡需护照） | 200 美元/月 | 不退款 | 低 |
| 苹果内购 + 美区礼品卡 | iPhone、美区 Apple ID、美区礼品卡 | 249.99 美元/月 | 可找苹果退款 | 高 |

关键：**IP、账单地址、卡三者要对得上**。网页路线选 **Pro 月付 20 美元**（别选成 200 美元/年的 Pro 年付）。苹果路线先用 20 美元开 Pro，别新号当天就大额充值+订阅（会被苹果风控限购）。

## 七、接上 Claude Code

- 推荐命令行（CLI）版 Claude Code，不用桌面客户端（权限更高、信息拿得多）；
- 让 Agent 按 `code.claude.com` 官网方式安装，终端运行 `claude` 登录；授权链接复制到指纹浏览器窗口内打开；
- 日常守住三条红线：不开高并发会话、不把订阅反代成 API/接中转、不聊违规内容。

---

## 八、Pro 升级 Max

- **时机**：Pro 用 5 次左右、隔一天再升，别刚开就换 200 美元 Max；
- 网页路线：网页订阅设置里直接升级；
- 苹果路线：先兑 250 美元礼品卡 → 认准 **Max 20x 月付 249.99**（别选 Max 5x）→ 余额备够（升级立即全额扣款，Pro 剩余按比例退回）→ 弹"无法购买"时在比特浏览器里走 `getsupport.apple.com` → **Live Chat** → 报邮箱 + Support PIN → 动之以情沟通，索要"72 小时后一定能买"的确定答复；
- **续费别断**：苹果自动续费，扣费前 5~10 天提前备好礼品卡余额。
